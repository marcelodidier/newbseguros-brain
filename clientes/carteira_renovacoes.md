# 🔄 Carteira — Renovações

> Atualizado automaticamente pelo sistema de monitoramento

## Formato para Registro

| Campo | Descrição |
|-------|-----------|
| Nome | Nome do cliente |
| Email | Contato principal |
| Telefone | WhatsApp |
| Tipo Seguro | Produto contratado |
| Seguradora | Empresa atual |
| Vencimento | Data de vencimento da apólice |
| Prêmio Anual | Valor da apólice |
| Responsável | Consultor da NewB |
| Status | Em dia / Urgente / Em negociação |

## Critérios de Urgência
- 🔴 **Urgente**: vence em menos de 7 dias
- 🟡 **Em breve**: vence em 8-30 dias  
- 🟢 **Em dia**: vence em mais de 30 dias
